# ととのえる

「ととのえる」は、2枚のタイルを入れ替えて見本と同じ模様にする、1〜3分ほどのブラウザ向けパズルです。1回につき3問で必ず終わります。タイマー、点数、連続記録などはありません。

## 起動方法

1. このフォルダの `index.html` をダブルクリックします。
2. ブラウザでそのまま遊べます。

インストール、ビルド、インターネット接続は不要です。

## 遊び方

1. 「やさしい（2 × 2）」または「ふつう（3 × 3）」を選び、「はじめる」を押します。
2. 「見本」を確認します。
3. 「いまの並び」からタイルを1枚選び、続けてもう1枚選ぶと、2枚の位置が入れ替わります。
4. 見本と同じ並びに整えると、その問題は完成です。3問を終えると終了画面になります。

補助操作として次を使えます。

- **ヒント**: 入れ替えると1枚が正しい位置に戻る2枚を、点線で示します。
- **1手戻す**: 直前の入れ替えを取り消します。
- **最初からやり直す**: その問題が始まったときの並びに戻します。

## キーボード操作

- `Tab`: ボタンやタイルの間を移動
- 矢印キー: 盤面内の隣のタイルへ移動
- `Enter` / `Space`: タイルやボタンを選択

## 自動テスト

Node.js がある環境では、次のコマンドで主要なゲームロジックを確認できます。

```text
node tests.js
```

ゲーム本体には外部ライブラリ、外部通信、API、保存機能を使用していません。
